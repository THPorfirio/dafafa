# Fafá atelier — revisão 2026

Revisão técnica de um projeto acadêmico originalmente desenvolvido durante a graduação em Design Gráfico.

## Principais melhorias
- revisão de responsividade para desktop, tablet e mobile;
- CSS de modernização separado em `css/modern-2026.css`;
- redução de dependências antigas de jQuery/Popper;
- navegação e foco de teclado revisados;
- formulário com labels, IDs únicos, seleção real de produtos e validação nativa;
- melhoria de semântica, textos alternativos e metadados básicos;
- remoção de arquivos de teste, cópias e arquivos de sistema da entrega;
- preservação dos elementos visuais e conteúdo original sempre que possível.

## Observação
O formulário desta versão não envia dados para um servidor. Ele valida os campos e informa que é necessário conectar um serviço de formulário ou backend para o envio real.
